# Рабочий день

Таймер рабочего дня: сколько осталось, сколько прошло в процентах и листаемая лента сцен,
которые показывают прогресс дня по-разному — стрелок, костёр, рыбалка, жизнь Батрака, поезд до Владивостока, карта России.

- Сайт — `index.html`, ядро — `core/`, сцены — `scenes/`.
- Хотите добавить свою сцену — читайте [CONTRIBUTING.md](CONTRIBUTING.md).
- Локально: `npm run dev` → http://127.0.0.1:8080/
