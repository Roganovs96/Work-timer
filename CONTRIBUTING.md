# Как добавить свою сцену

Сайт показывает таймер рабочего дня, а посередине — листаемую ленту сцен: стрелок, костёр, поезд и так далее.
Каждая сцена по-своему показывает, **сколько прошло и сколько осталось рабочего дня**. Вы можете придумать свою.

## Коротко

1. Сделайте форк репозитория.
2. Скопируйте `scenes/_template/` в `scenes/<имя>/` (латиница в нижнем регистре, цифры, дефис: `rocket`, `coffee-cup`).
3. Допишите `'<имя>',` в конец `scenes/list.js`.
4. Запустите `npm run dev`, откройте http://127.0.0.1:8080/dev.html?scene=<имя> и рисуйте.
5. Проверьте `npm test` и откройте Pull Request.

## Правила

- **Меняйте только свою папку** `scenes/<имя>/` и одну строку в `scenes/list.js`. Шапку, футер, ядро (`core/`), тесты и чужие сцены трогать нельзя — PR с такими изменениями не пройдёт проверку.
- Одна сцена — один PR.
- Сцена должна честно показывать прогресс дня: глядя на неё, можно понять, сколько прошло.
- Папка — не больше 150 КБ. Файлы: `.js`, `.png`, `.jpg`, `.webp`, `.svg`, `.json`, `.md`.
- Без сети, без чужих скриптов и без хранилищ браузера: сцена работает в песочнице, где всё это заблокировано.
- Только своё или свободно лицензированное. Без чужих брендов, персонажей и копий известных игр.
- Ничего оскорбительного и 18+.

## Как устроена сцена

Сцена — это файл `scenes/<имя>/scene.js`. Ядро открывает его в изолированном iframe и 10 раз в секунду сообщает время.
Холст, кнопки и подписи сцена рисует сама внутри своего iframe.

```js
const cv = makeCanvas();          // холст на всю сцену
let g = null;

function set(k, force) {          // 10 раз в секунду; force — сцена сменила размер
  if (force || !g) { g = { W: area.clientWidth, H: area.clientHeight }; fitCanvas(cv); }
}

function frame(now) {             // каждый кадр, пока сцену видно
  beginFrame(cv, g);              // очищает холст, ctx — его контекст
  const p = livePct();            // сколько прошло, 0…100, плавно
  ctx.fillStyle = '#4f9cff';
  ctx.fillRect(0, g.H - 20, g.W * p / 100, 20);
}

registerScene({
  name: 'Полоска',                // название в ленте, до 24 символов
  author: 'ваш-ник',
  words: ['кусочек', 'каждые', 'следующий кусочек', 'следующий'],
  steps: 100,                     // на сколько частей делится день (по умолчанию 300)
  set, frame,
});
```

### Что передать в `registerScene`

| Поле | Обязательно | Что это |
|---|---|---|
| `name` | да | Название в ленте, до 24 символов |
| `author` | нет | Ваш ник |
| `frame(now)` | да | Рисует кадр. Вызывается, только пока сцену видно |
| `set(k, force)` | нет | Получает номер текущей части дня `k` (0…`N`). `force` — изменился размер |
| `words` | нет | 4 слова для шапки: «`[0]` `[1]` 1:48» и «`[2]` через 0:30» (на телефоне `[3]`) |
| `steps` | нет | На сколько частей делится день для подписи в шапке |
| `sub()` | нет | Своя подпись в шапке вместо `words`: массив `{ t: 'текст' }` и `{ ms: 90000, b: true }` (время, жирным) |
| `tick()` | нет | Вызывается 10 раз в секунду — удобно обновлять HTML-подписи |
| `onFast(f)` | нет | Включили (`f = { per }`) или выключили (`null`) «Уйти пораньше» |
| `onTap(x, y)` | нет | Нажатие на сцену |

### Что доступно внутри сцены

| | |
|---|---|
| `curPct`, `curK`, `N` | Сколько прошло: процент, номер части, всего частей (300) |
| `livePct()`, `leftMs()`, `dayLenMs()` | То же, но плавно для анимации; осталось и длина дня в мс |
| `fast` | `{ per }` в режиме «уйти пораньше» (`per` — мс на одну часть), иначе `null` |
| `isFat(r)`, `isHat(r)` | На части `r` кончается час; каждая 10-я часть |
| `makeCanvas()`, `fitCanvas(c)`, `beginFrame(c, g)`, `ctx` | Холст |
| `area.clientWidth`, `area.clientHeight` | Размер сцены |
| `html(markup)`, `css(text)`, `$(id)` | Свой HTML и стили поверх холста |
| `rng(seed)`, `lerp`, `smooth`, `pickGrid`, `walker(...)`, `fmt(ms)` | Помощники |
| `sceneStore.get(k, def)` / `.set(k, v)` | Сохранить маленькую настройку (до 2000 символов) |

Всё это — в `core/sdk.js`. Шесть готовых сцен в `scenes/` — хорошие примеры: от простых (`fire`) до сложных (`train`, `map`).

## Проверка

```bash
npm install
npx playwright install chromium
npm run dev          # песочница: http://127.0.0.1:8080/dev.html
npm test             # все проверки
```

В песочнице можно двигать ползунок дня, ускорять время, включать «Уйти пораньше» и менять размер экрана.

Тесты проверяют каждую сцену на телефоне и компьютере:

- загружается и вызывает `registerScene`;
- рисует что-то при 0%, 0,4%, 37%, 82%, 99,9% и 100%;
- без ошибок, в том числе в режиме «Уйти пораньше»;
- кадр в среднем не дольше 12 мс;
- не ходит в интернет и не использует запрещённое (`eval`, `fetch`, `parent`, `localStorage` и т. п.);
- шапка и футер после неё работают.

Скриншоты сцен складываются в `tests/output/`.

## Что будет после PR

1. GitHub Actions проверит, что PR меняет только вашу сцену, и прогонит тесты. Итоги и скриншоты — во вкладке **Checks**.
2. Владелец посмотрит сцену и, если всё хорошо, одобрит и вольёт.
3. Через пару минут сцена появится на сайте.
